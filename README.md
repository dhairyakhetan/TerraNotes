# fahhh

This branch is a single page: an animated rainbow 3D "fahhh" (`index.html`, plain HTML and CSS, nothing to install).

The TerraNotes magazine site, everything that was here before, lives on the **`fahhh`** branch.

`og.png` is its link preview (the page itself at 1200×630). `npm run build` copies both into `dist/` (what Vercel serves; see `vercel.json`).
